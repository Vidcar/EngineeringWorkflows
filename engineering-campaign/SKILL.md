# Run the requested bounded program

Select only when the user directly requests program or queue orchestration; a
natural-language request is sufficient. Never start it as an unsolicited setup or
support step. A requested component retains the existing lead. Resolve engineering-workflows by exact
catalog name and read its references/contract.md once per task without invoking
it. If unavailable, preserve scope, authority and user work while reporting the
limitation. Organizing a program adds no deployment, messaging, spending or
background scheduling authority. Preserve established permission; plan-only ends
at the plan.

Define the outcome, exclusions, dependent units, authorized finish, acceptance
checks and resource/stop bounds. Keep one coordinator responsible for integration
and one durable program record. Read [state-and-control.md](references/state-and-control.md)
before dispatch or resume, and the shared coordination.md for isolation,
cross-host transfer and writer replacement.

Dispatch bounded units to Workflows for investigation/planning/implementation,
Check for assessment, Verify for defined proofs, Measure for comparisons or Arena
for alternatives. Pass ownership, input identity, allowed writes, inherited review
depth, budget and return conditions. Units cannot start another campaign or
restart the overall lifecycle. Do not invoke Configure automatically.

Prove a representative unit before scaling repetitive work. Schedule dependencies
against checked inputs and isolate concurrent writers and runtime resources.
Inspect actual outputs and failures; use proportional independent scrutiny from
the shared contract. Diagnose stalled work and bounded retries instead of spawning
competing replacements. Never infer progress from a worker's narrative alone.

Integrate through one owner and recheck the combined outcome. Finish at the
requested authorized boundary; for external delivery read the shared delivery.md
and confirm actual destination state. Report each unit's real status, useful
proof, unresolved findings and next action. On STOP, halt new effects and confirm
writers stopped; preserve unfinished work and evidence. Do not claim monitoring
continues without an explicitly requested, supported persistent mechanism.
