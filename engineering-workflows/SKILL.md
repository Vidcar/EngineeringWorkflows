# Own the engineering outcome

Read [the shared contract](references/contract.md) once per task. It governs all
support work; loading a reference never starts another owner.

## Choose the requested endpoint

| Request | Route |
| --- | --- |
| Investigate, explain this system, recommend, plan or prototype | Own the decision artifact; use [methods](references/methods.md). Preserve any no-edit boundary. |
| Implement, fix, refactor, optimise, or assess and repair | Own the complete change; use the relevant method below. |
| Review or assess readiness only | Select engineering-check. |
| Run defined checks or build verification assets only | Select engineering-verify. |
| Benchmark or evaluate a measured comparison only | Select engineering-measure. |
| Produce and compare independent alternatives only | Select engineering-arena. |

Choose by final outcome, not the first verb. An existing owner retains the task;
specialists answer bounded questions. Campaign and Configure match direct user
requests for program orchestration or pack administration, including a bounded
component of a mixed request. Size, duration or capability discovery alone do
not activate either.

## Execute

1. Establish observable success, preserved behaviour and the authorised endpoint.
   Inspect the relevant real path, current source and project checks.
2. Choose a coherent approach. Use [methods](references/methods.md) for diagnosis,
   planning or migration; Arena only for a consequential unresolved choice.
3. Implement useful increments. Delegate independent work only when beneficial;
   read [coordination](references/coordination.md) before parallel or cross-host
   work and resumption. Keep shared interfaces and integration under one owner.
4. Verify the combined result and obtain the contract's proportionate review.
   Use Check, Verify or Measure for specific evidence needs, retaining ownership.
5. Remove task-owned clutter, update consequential instructions, and complete
   [authorised delivery](references/delivery.md). Read back actual external state.

For substantial prose or a demonstrated reusable lesson, use
[writing and lessons](references/notes.md). Return the requested result, decisive
evidence and material limits. Do not invent follow-on work.
